# Athlete Database App

A simple athlete and coach database that runs entirely in the browser. No Python or server required.

## Files
- index.html
- register-athlete.html
- register-coach.html
- athletes.html
- styles.css
- script.js

## How to use
1. Download or unzip all files into one folder.
2. Double-click `index.html` to open it in your browser.
3. Create athlete profiles or coach profiles.
4. Browse and search athletes on the Browse Athletes page.

All data is saved in your browser’s localStorage. Clearing your browser data will erase the profiles.
